## 1. 現況盤點（來自本 repo）

- 形態：靜態 PWA ＋ Vercel serverless，沒有 build 框架。已可「加到主畫面」。
- 資料：預設全在本機；「星塵帳號」是端對端加密同步（伺服器只存密文，`api/account.js` 已有 `destroy` 刪帳號）。
- **會燒錢的只有三處**：
  1. 夢汐 AI（`api/ai-chat.js`，預設模型 `claude-opus-4-8`，**逐則計費**，免費用戶不設上限會失控）。
  2. 星塵帳號雲端同步（Upstash Redis，儲存與請求量計費）。
  3. 宇宙新聞（`api/space-news.js`，CDN 一週只回源一次＋一週翻譯一次，成本可忽略）。
- 已有的合規基礎：「非醫療用途」聲明、水晶功效「民俗與能量傳統整理」聲明、AI 提示詞內建危機轉介（1925／1995）、AI 不診斷。

## 2. 上架路線

### Google Play（先做）
- 用 **TWA**（Trusted Web Activity，PWABuilder／Bubblewrap 產生）把 PWA 包成 Android App；不改前端架構。
- 需要：Google Play 開發者帳號（⚠️ 一次性註冊費，約 US$25，未核實）、隱私權政策網址、Data safety 表單、圖示與截圖、Digital Asset Links（網域驗證）。
- 訂閱走 Google Play Billing（Play 的 TWA 支援 Digital Goods API）。

### Apple App Store（第二階段）
- 需 Apple Developer Program（⚠️ 年費約 US$99，未核實）＋ Mac／Xcode，或用雲端 CI。
- 純網頁外殼容易被 **4.2 最低功能**退件。要用 **Capacitor** 包，並加入真正的原生價值，例如：
  - 本機排程通知（滿月／新月許願提醒——現在 PWA 版已移除背景推播，這是最自然的補強）
  - Face ID／指紋 App 鎖（保護日記與夢境，也呼應隱私賣點）
  - 分享選單、相簿／相機整合、桌面小工具（今日月相）
- **帳號刪除**：有建立帳號就必須能在 App 內發起刪除（Apple 5.1.1(v)）。`destroy` API 與設定頁「🗑 刪除雲端帳號」入口都已有（`account.js`）；送審前確認整個流程能在 App 內完成、入口夠明顯。
  ⚠️ 2026-10-15 審查發現：刪除只讓「當下這台」的 session 失效，其他裝置仍登入時會把密文寫回雲端；且忘記密碼的人無法刪帳號。送審前要先補（見 `docs/account-next-steps.md` §3.5）。
- 數位內容訂閱必須走 Apple IAP；**預約諮詢（真人服務）**屬 App 外使用的服務，外連 `booking.bluechiou.com` 通常可行（⚠️ 送審前對照 3.1.3(e) 原文確認，並避免在 App 內賣「數位內容」又繞過 IAP）。

### 兩邊共通的送審清單
- 隱私權政策＋服務條款（繁中／英）：明寫「紀錄預設只在你的裝置；帳號同步為端對端加密，我們看不到內容」。
- 隱私標籤／Data safety：只如實填「Email（帳號）、購買紀錄、診斷資料（若有）」；**不要**為了好看而少填。
- 年齡分級、內容分類：選「生活風格／健康與健身」二擇一，避免「醫療」類別（會被要求更多證明）。
- 心理健康相關 App：保留醒目的「非醫療、不能取代專業協助」，並在夢汐與「颱風天」安慰視窗保留求助資訊。
- 水晶「功效」：維持「民俗與能量傳統整理、非科學實證」聲明，不寫治療、治癒、保證等字眼。

## 3. 收費模式比較

| | 純免費 | 廣告＋付費去廣告 | **免費核心＋訂閱（建議）** |
|---|---|---|---|
| 收入 | 0 | 低（小眾 App 展示量少） | 中，可預測 |
| 隱私賣點 | 完整 | **被破壞**：廣告 SDK 會收裝置資料，與「端對端加密、夢境日記不外流」互相矛盾；商店隱私標籤也要改填 | 完整 |
| 信任（情緒／夢境／健康資料） | 高 | 低 | 高 |
| 營運成本風險 | AI 費用無上限 | 同左 | 可控（AI 與同步只給訂閱者／設額度） |
| 實作 | 無 | 廣告 SDK＋同意管理（GDPR／ATT） | 商店內購 ＋ 收據驗證 |

**不建議放廣告**：這類 App 的核心資產是「安心寫下最私密的東西」，廣告會直接傷到它。

## 4. 建議的功能分層

**永遠免費（不要鎖）**：夢境／日記／心情／思考紀錄、月曆與即時月相、水晶圖鑑、天象與宇宙新聞、專欄、每日顯化、**任何求助資訊與危機轉介**。
→ 這樣商店審核與口碑最安全，也符合「記錄自己」的初衷。

**星塵 Plus（訂閱）**候選（依成本與價值）：
1. 夢汐 AI 陪伴／解夢：**免費每天少量（例如 3 則）**，Plus 放寬（用 Haiku 級模型控成本）。
2. 端對端加密雲端同步＋多裝置（有 Redis 成本）。
3. 進階報告與匯出（回診／諮商用報告、PDF）。
4. 水晶收藏架完整功能（相片、無限收藏）、召喚祭壇全部背景、主題與月相圖示組。
5. 提前使用新功能。

**另賣（可選）**：一次性買斷（建議價 NT$1,990，⚠️ 假設值）給不喜歡訂閱的人；預約系統導流不抽成。

## 5. 定價與損益（要用數據校準）

假設（⚠️ 皆為待驗證假設，不是事實）：
- 訂閱：月 NT$99、年 NT$790、首次 7 天試用。
- 平台抽成：Apple Small Business Program 年收入 ≤ US$1M 可適用 **15%**（官方頁面有寫；訂閱是否整段都 15% 以現行條款為準）。Google 訂閱約 **15%**（⚠️ 2026 年有「服務費＋計費費」拆分的報導，細節各來源不一）。
- 稅：商店通常代收代繳消費稅（⚠️ 台灣個人／公司接收款項的營業稅與所得稅，請洽會計師）。

淨收入每位訂閱者每月 ≈ 99 × (1 − 0.15) ≈ **NT$84**（未計稅）。
**單位經濟學公式**：`每位訂閱者月毛利 = 84 − AI 成本 − 同步成本`。
→ **上線前先做的一件事**：在 `api/ai-chat.js` 加匿名用量計數（只記 token 數，不記內容），量 2 週取得「每位活躍用戶每月 AI 成本」，再決定免費額度與是否要調價。不要在沒數據時就公布價格。

簡單目標：每月固定成本（Vercel＋Upstash＋開發者帳號攤提）通常很低，**約 10–20 位年費訂閱者即可打平基本雲端成本**（⚠️ 依實測成本重算）。

## 7. 風險與對策

- **Apple 4.2 退件**：用 §2 的原生功能降低風險；送審備註清楚說明功能與測試帳號。
- **AI 費用失控**：免費額度＋Haiku 級模型＋每日上限；用量計數先做。
- **隱私承諾被稀釋**：任何新增 SDK（分析、崩潰回報）先過 CLAUDE.md §1，不收明文；分析只收匿名事件。
- **健康／玄學宣稱**：維持「非醫療、非科學實證」聲明，行銷文案不寫療效。
- **後台誤改**：文案後台有 20 版歷史可還原（見 `docs/admin-setup.md`）。
- **單點維運**：Vercel／Upstash／Anthropic 任一掛掉的降級行為（App 已設計成降級：AI 不可用時其他功能照常）。
